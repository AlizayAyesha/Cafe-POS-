# What The Food — Staff Training Guide

Phase 1 Café POS

## Cashier — daily flow

1. Sign in with your staff email.
2. Open the register (enter opening float).
3. Ring up items on POS.
4. Apply discount only if allowed / instructed.
5. Take payment (cash, card, split, or gift card).
6. Tap **Complete**. Print receipt if needed.
7. Hold an order if the guest steps away; resume later from Held.

## Supervisor

- Void / return completed sales (reason required).
- Close register (count cash; variance is recorded).
- Inventory adjustments, receivings, expenses.
- Gift cards: issue / reload for repeat customers.

## Admin

- Products, categories, staff, settings, audit log.

### Local practice logins

A local database can create missing demo staff when you set `DEMO_SEED_PASSWORD` and run `npm run db:seed`. The sign-in page does not display that password. Ask the admin for the password you chose. Do not reuse a practice password on the live site.

The café has one shared cash drawer for every device.
